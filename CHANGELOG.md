# Changelog

All notable changes to Issue Scout will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-08-08

### Added
- Core skill implementation
- SKILL.md with complete workflow
- README.md with documentation
- Example files for different use cases
- Reference documentation
- Test simulation

Known issues in this release: GitHub CLI authentication is required for private
repositories, and rate limiting may affect large-scale searches.

## [0.0.1] - 2026-08-08

### Added
- Initial project structure
- Basic skill documentation
- Example scenarios

## Version History

- **0.0.1**: Initial development version
